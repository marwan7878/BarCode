# 📦 BarCode

A web-based barcode generator and decoder built with **ASP.NET Core MVC**, **ZXing.Net**, and **ImageSharp**.  
It allows you to create barcode images for products and decode barcodes from uploaded images.

---

## 🚀 Features

- ✅ Generate barcodes (Code128 format supported)
- ✅ Decode barcodes from uploaded images
- ✅ Display barcodes in your browser
- ✅ Save generated barcodes as images
- ✅ MVC architecture with Service and Repository pattern
- ✅ Entity Framework Core integration

---

## 🧰 Technologies Used

- ASP.NET Core MVC (.NET 7+)
- ZXing.Net (Barcode scanning/decoding)
- ZXing.Net.Bindings.ImageSharp.V2 (ImageSharp decoding support)
- SixLabors.ImageSharp (image creation/editing)
- Entity Framework Core
- SQL Server (or any EF Core-supported database)

---

## 📦 Prerequisites

- [.NET 7 SDK](https://dotnet.microsoft.com/en-us/download)
- SQL Server or LocalDB
- Visual Studio 2022+ or Visual Studio Code
